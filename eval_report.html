About the Project

What is the LLM Router?

The LLM Router is intelligent middleware between your app and the AI model ecosystem. Instead of blindly sending every query to an expensive frontier model, it analyzes intent, complexity, and requirements — then routes to the most cost-effective model that can handle it correctly.

⚡

Layer 1 — Heuristics

Lightning-fast rule-based analyzer running in under 1ms. Uses keyword patterns, query length, and signal matching to classify complexity. If confidence ≥ 80%, decides instantly — no API call needed.

🧠

Layer 2 — LLM Classifier

When heuristics aren't confident enough, Groq's llama-3.1-8b-instant acts as a fast meta-router. Makes final classification in ~700ms average — cheap at $0.05/M input tokens.

🏆

Reward-Based Model Scoring

Once a tier is chosen, a scoring algorithm picks the best model — not just cheapest. Weighs price, context window size, and capability bonuses (vision, thinking, coding) together.

📐

Context-Aware Selection

Estimates minimum context window needed from query length + file size. Guarantees the selected model has enough token space — critical for large-document, simple-task edge cases.

Objectives

What We Aim For

Built on a core belief: most AI queries don't need a $25/M output token frontier model. Smart routing means matching the right model to the right task — every time.

💰

Radical Cost Reduction

Route simple and medium queries to cheap models, saving frontier models for queries that genuinely need them.

🎯

Accuracy First

Never sacrifice correctness for cost. Coding queries must reach coding models. Vision queries must reach vision models.

🚀

Sub-2ms Heuristic Decisions

For high-confidence cases, routing should be instantaneous — adding effectively zero overhead to the user experience.

📏

Context Window Awareness

Never send a 50,000 word document to a model with a 32k context window. Always pick a model that can fit the input.

🔍

Edge Case Handling

A massive paragraph + "find this word" stays Tier 3 — not sent to an expensive model just because input is large.

🔄

Live Model Catalog

Pull models from OpenRouter's live API with automatic tier assignment. No hardcoded lists that go stale overnight.
